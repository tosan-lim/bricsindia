# BRICS India WordPress custom code

This repository contains the custom WordPress theme for the BRICS India site.

WordPress core, third-party plugins, uploads, backups, cache files, and local configuration are intentionally excluded.

Custom code:

- `wp-content/themes/brics-modern`
- `wp-content/mu-plugins/brics-contact-mail.php`
- `wp-content/mu-plugins/brics-disable-comments.php`
- `wp-content/mu-plugins/brics-seo.php`
